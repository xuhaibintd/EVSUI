# 公開前検査

> **言語:** [English](publishing.md) | 日本語
<!-- Source-SHA256: 5d5c70438fda68d1b26bec524355e7ce50efbfdb3a3b793f8bda16fb74ae8480 -->

変更をコミットまたはプッシュする前に、公開前検査を実行してください。

```powershell
uv run --locked --no-sync python scripts\check_publication.py
uv run --locked --no-sync python scripts\check_doc_parity.py
```

この検査は現在 Git で追跡されているツリーを調べ、ランタイムデータ、環境ファイル、認証情報とキーフォーマット、社内向けの日付付きレポート、マシン固有のユーザーパス、および英語以外の主要ドキュメントを拒否します。ローカル設定を利用できる場合は、保存済みの接続値と認証情報の値を表示せずに、追跡対象ファイルと比較します。CI はすべてのプッシュとプルリクエストで同じ検査を実行します。

公開例では、`example_database`、`EXAMPLE_STORE`、`example.invalid` などの架空の識別子を使用してください。実行固有のレポート、スクリーンショット、環境メモ、顧客またはデプロイ識別子は、追跡対象外の `local-notes/` ディレクトリに保存してください。翻訳は `_ja.md` など、言語を明示する接尾辞を付けたファイルで管理します。README と接尾辞のないドキュメントは英語で管理します。公開されるすべての英語 Markdown 文書には、見出し、リスト、表が同じ構造を持ち、フェンス付きコードが同一である完全な `_ja.md` 対応文書が必要です。英語文書の変更を翻訳した後、日本語ファイルの `Source-SHA256` マーカーを更新してください。文書パリティ検査は、翻訳の欠落、構造の相違、古い翻訳、および壊れているか不適切にローカライズされた文書間リンクを拒否します。

このチェッカーは現在のツリーを検証するものであり、過去の Git 履歴は検証しません。認証情報を一度でもコミットした場合は、直ちにローテーションしてください。最新リビジョンから削除しても、古い値が再び秘密になるわけではありません。公開済み履歴の書き換えは別のリポジトリ管理操作であり、既存のクローンおよびフォークを使用するすべてのユーザーとの調整が必要です。

ライセンス、商標の使用、第三者通知、および組織の承認は個別に確認してください。自動検査では、公開に必要な法的承認を確定できません。
