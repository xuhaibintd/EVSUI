## 截图问题的复现和修复

Document Metadata 和 Document Relationships 的刷新按钮与 `required` 下拉框位于同一个表单。
尚未加载列表时，下拉框为空；点击 Refresh Vector Stores 被浏览器原生校验拦下，后端请求数为 **0**。
两个刷新按钮现均使用 `formnovalidate`，普通 Load 仍要求选择。空列表提示解释刷新/选择/加载顺序。
回归测试实际点击两个按钮，检查请求发出、列表返回，并继续执行后续治理操作。

## 本轮查出的其他缺陷

| 问题 | 修复与验证 |
|---|---|
| Vector Store 行选择使用 `hx-vals='js:…'`，被 CSP 阻止 | 改为静态 JSON；真实浏览器验证选择、删除取消、删除确认 |
| 系统连接删除使用内联 `onclick`，确认框被 CSP 阻止 | 外部委托事件处理；取消后记录必须仍存在 |
| Connect 成功但聊天/创建等控件仍保留断开时的禁用状态 | 返回完整关联面板的 OOB 更新；验证连接、断开和重新导航 |
| 导航/模式切换错误地重新启用隐藏字段和不可用按钮 | 只恢复连接门禁禁用的控件；集中计算条件字段状态；检查实际 FormData |
| 创建参数统一截断为 50 字符，密钥、路径和提示词被静默破坏 | 前后端取消统一截断，按字段长度校验；长密钥验证到加密任务入队 |
| Provider API Key 为可见文本输入 | 使用 password 输入，不回显已保存密钥 |
| JSON Inspector 零匹配时保留上一次详情 | 清除旧详情和旧选中状态，恢复匹配时重新选择 |
| JSON Inspector Refresh 只刷新详情，文件下拉列表不更新 | 文件选择框 OOB 更新；真实浏览器测试页面打开后新增 JSON、刷新、打开、文本安全显示及错误文件 |
| 新建连接借用了默认连接的密码/PAT/PEM 状态 | 新建与编辑分开处理；新建必须独立提供凭据 |
| Viewer 可以调用创建、删除、上传和治理写路由 | 后端动作权限检查；前端不呈现不可用写操作 |
| 断开会话的治理操作可能访问进程遗留 SQL 上下文 | 写操作和导出检查连接；读取页面断开时不查询数据库 |
| 用户导入替换密码后旧会话仍可用 | 撤销被替换用户会话；当前管理员被替换后返回登录 |
| 畸形/非 ASCII Origin 或 API Token 触发 500 | 安全拒绝无效值；加入真实 HTTP 用例 |
| 检索未连接返回 500，schema 读取错误依赖连接 | 明确 409/503 状态；静态 schema 不启动 SDK |
| answer 响应 query_plan 为 None 不符合声明，HTTP 序列化失败 | 使用空字典默认值；GET/POST 成功响应及历史隔离验证 |
| Metadata CSV 第 2 行错误时第 1 行已写入 | 整批先验证再写；空文件/错误表头也拒绝 |
| 解析入口接受空文档并排入后台任务 | 无上传文件时返回 422；已有文档的独立解析允许尚未命名 Vector Store，与分步 UI 保持一致 |
| Multipart 上传成功/失败路径未关闭临时文件 | 请求 finally 关闭 FormData，并关闭接受、跳过和待处理的上传文件；覆盖 spool rollover |
| Durable create 遗漏已存在检查、已装载源表/索引完整性检查 | 恢复前置检查；空索引、缺行、多行不能报告成功 |
| 同一 job 的旧 attempt 可能覆盖重新领取后的结果 | 原子领取、attempt fencing；并发与过期 worker 回归 |
| 损坏加密 payload 或未知 handler 阻塞队列 | 单任务失败隔离；未知类型不领取 |
| 单文件解析失败被包装为成功任务，manifest 错误可能包含密钥 | 保留脱敏逐文件失败结果，任务标记 failed；写盘前脱敏 |
| 超时错误暗示远端已停止 | 保留远端 creating 状态并明确操作可能继续 |
| CSV ready 结果可在另一数据库连接上被错误复用 | manifest 绑定 profile ID 和 Host/Username/UES URL 目标指纹；同 ID 修改目标也拒绝，单纯轮换凭据仍可复用 |
| Vector Store 存在性检查将错误 JSON 当作空列表 | 仅接受有效集合/记录或独立状态确认，无法识别或错误输出不能绕过前置检查 |
| 中断 CSV loading 被盲目重试或无法解释 | 明确要求检查旧 loader/目标表后新建 run；失败路径零 SQL 写入 |

## 验收边界

真实 Teradata DDL/DML、真实 Unstructured 解析、付费模型输出和性能压测没有在业务数据上执行，
这些不计为“已通过”。浏览器成功流程中的远端结果使用测试替身，底层转换/任务行为另有回归测试。
本轮不修改数据库 schema，不迁移/清空原数据，不自动启动 worker 消费现有队列。
单个 CSV 批次执行中途数据库异常的整体事务回滚，以及多个不同 job 操作同一资源的分布式锁仍不作保证。
